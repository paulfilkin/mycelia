# Keyboard shortcuts

These are the keyboard shortcuts in Mycelia.  They work from any workspace while the main window is in front.

## Files and changes

| Shortcut | What it does |
| --- | --- |
| Ctrl+N | Start a new tree |
| Ctrl+O | Open a tree or a GEDCOM file |
| Ctrl+S | Save the tree |
| Ctrl+Z | Undo the last change |
| Ctrl+Y | Redo the change you undid |
| Ctrl+F | Find and replace |

## People

| Shortcut | What it does |
| --- | --- |
| Alt+Left | Back to the previous person |
| Alt+Right | Forward again |
| Ctrl+Home | Go to the home person |
| Ctrl+Shift+B | Add or remove a bookmark for the selected person |
| F3 | Open the Person view |
| Shift+F10 or the Menu key | In the index, the right-click menu for the selected person |

## Workspaces

| Shortcut | What it does |
| --- | --- |
| Ctrl+1 | Home |
| Ctrl+2 | People |
| Ctrl+3 | Places |
| Ctrl+4 | Media |
| Ctrl+5 | Sources |
| Ctrl+6 | Charts |
| Ctrl+7 | Tools |
| Ctrl+D | Tools, where the date calculator is |

Ctrl+4 opens Media and Ctrl+5 Sources, although the Sources tab comes before Media in the top bar.  The digits on the number pad work as well as the ones above the letters.

## Help

| Shortcut | What it does |
| --- | --- |
| F1 | Open the help page for the screen you are on |

## Other keys

| Key | Where | What it does |
| --- | --- | --- |
| Ctrl+mouse wheel | The Tree panel in the People workspace | Zoom in and out |
| Enter | The Assistant's message box | Send the message |
| Shift+Enter | The Assistant's message box | Start a new line |
| Enter | The **Find** box in Find and replace | Find |
| Enter | Most windows, outside a box that takes several lines | Choose the window's main button, such as **OK** or **Add** |
| Esc | Most windows | **Cancel** |

See [Getting started](getting-started.md) for undo, Back and Forward, and [The People workspace](people.md) for bookmarks and the home person.
